# ScannerLib

Терминальное TUI-приложение на C++20 для сканирования директорий на предмет вредоносных файлов по базе хешей. Рекурсивно обходит заданную директорию, вычисляет хеш каждого файла через OpenSSL в пуле потоков и сверяет с базой. Поддерживаются алгоритмы MD5 (устарел), SHA1 и SHA256. Найденные совпадения и ошибки пишутся в лог-файл, процесс отображается в интерактивном интерфейсе.

## Сборка

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

На macOS нужны OpenSSL и (для тестов) GoogleTest из Homebrew. FTXUI подтянется через `find_package` или `FetchContent`.

## Руководство по запуску

Приложение всегда открывает TUI. Аргументы командной строки только **предзаполняют** поля формы; если путь для скана не задан — его нужно ввести в интерфейсе.

Формат базы (`hashes.csv`):

```text
<хеш>;<вердикт>
```

Пример лежит в корне проекта: [`hashes.csv`](hashes.csv). Алгоритм хеширования в CSV должен совпадать с выбранным в приложении (по умолчанию SHA256).

### TUI (интерактивно)

Самый простой способ — через обёртку (подставит базу и лог из корня репозитория):

```bash
# если установлен симлинк в PATH:
scannerlib

# или напрямую:
./scripts/scannerlib
```

В форме уже будут:

| Поле | Значение по умолчанию |
|------|------------------------|
| База | `<корень_проекта>/hashes.csv` |
| Лог  | `<корень_проекта>/logs.txt` |
| Путь | пусто — укажите директорию для скана |
| Потоки | `4` |
| Алгоритм | `SHA256` |

Поля можно стереть и заменить своими. Дальше:

1. Заполните **Путь** (директория для рекурсивного сканирования).
2. При необходимости смените алгоритм (MD5 / SHA1 / SHA256).
3. Нажмите **Начать сканирование** или Enter.

Управление:

- `Tab` / стрелки — навигация по полям  
- `Enter` — старт сканирования  
- `q` — выход  

Без скрипта (поля пустые, всё вводите сами):

```bash
./build/scannerlib
```

Чтобы команда `scannerlib` была доступна из любой директории:

```bash
mkdir -p ~/.local/bin
ln -sf "$(pwd)/scripts/scannerlib" ~/.local/bin/scannerlib
# убедитесь, что ~/.local/bin есть в PATH
```

### CLI (предзаполнение через аргументы)

Аргументы задают значения в форме до открытия TUI. После запуска можно править поля вручную.

```bash
./build/scannerlib \
  --base /путь/к/hashes.csv \
  --log /путь/к/logs.txt \
  --path /путь/к/директории \
  --threads 8 \
  --algo sha256
```

Через скрипт (база и лог по умолчанию уже из корня проекта, можно переопределить):

```bash
./scripts/scannerlib --path /путь/к/директории --threads 8 --algo sha1
```

| Аргумент | Короткий | Описание |
|----------|----------|----------|
| `--base <csv>` | `-b` | Путь к CSV-базе хешей |
| `--log <файл>` | `-l` | Путь к лог-файлу (создаётся при необходимости) |
| `--path <dir>` | `-p` | Корневая директория для сканирования |
| `--threads <n>` | `-t` | Число рабочих потоков (по умолчанию `4`) |
| `--algo <имя>` | `-a` | Алгоритм: `md5`, `sha1` или `sha256` (по умолчанию `sha256`) |
| `--help` | `-h` | Краткая справка |

Примеры:

```bash
# только путь скана, база и лог — из корня проекта (через скрипт)
scannerlib --path ~/Documents

# полный набор аргументов
./build/scannerlib -b ./hashes.csv -l ./logs.txt -p ~/Downloads -t 4 -a sha256

# справка
./build/scannerlib --help
```

## Коды возврата

| Код | Значение |
|-----|----------|
| `0` | Успех |
| `1` | Фатальная ошибка (конфигурация, запуск) |
| `2` | Сканирование завершено, но были ошибки обработки отдельных файлов |

## Примечания

- MD5 криптографически устарел — используйте его только если база сигнатур в этом формате.
- Не запускайте утилиту с повышенными привилегиями без необходимости: лог может содержать чувствительные пути файловой системы.
