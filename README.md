# ScannerLib

Терминальное TUI-приложение на C++20 для сканирования директорий на предмет вредоносных файлов по базе MD5-хешей. Рекурсивно обходит заданную директорию, вычисляет MD5 каждого файла через OpenSSL в пуле потоков и сверяет с базой. Найденные совпадения и ошибки пишутся в лог-файл, процесс отображается в интерактивном интерфейсе на FTXUI.
