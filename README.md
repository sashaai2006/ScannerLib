# ScannerLib

Сканер директорий по базе хешей. Запуск:

```bash
scannerlib
```

Откроется форма: укажи папку в поле **Путь** и нажми Enter. База (`hashes.csv`) и лог (`logs.txt`) уже подставлены из корня проекта.

Клавиши: `Tab` — смена полей, `s` — остановить скан, `q` — выход (во время скана сначала останавливает).

## Что делает

Программа рекурсивно обходит выбранную директорию, считает хеш каждого файла (по умолчанию SHA256, можно MD5 или SHA1) и сверяет его с CSV-базой сигнатур. Совпадения показывает в TUI и пишет в лог вместе с вердиктом. Работа идёт в несколько потоков с ограниченной очередью задач.

Формат базы (`hashes.csv`):

```text
хеш;вердикт
```

## Коды выхода

- `0` — всё ок
- `1` — ошибка запуска
- `2` — скан прошёл, но часть файлов не удалось обработать

## Предостережения

- MD5 криптографически устарел.
- Не запускайте утилиту с повышенными привилегиями без необходимости: лог может содержать чувствительные пути файловой системы.
