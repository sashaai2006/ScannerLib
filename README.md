# ScannerLib

Терминальное TUI-приложение на C++20 для сканирования директорий на предмет вредоносных файлов по базе хешей. Рекурсивно обходит заданную директорию, вычисляет хеш каждого файла через OpenSSL в пуле потоков и сверяет с базой. Поддерживаются алгоритмы MD5 (устарел), SHA1 и SHA256. Найденные совпадения и ошибки пишутся в лог-файл, процесс отображается в интерактивном интерфейсе на TUI.
